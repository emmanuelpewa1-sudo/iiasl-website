# IIASL Website

A responsive, static multi-page website for the Indigenous Importers Association SL (IIASL).

## Pages
- Home
- About
- Gallery
- Dinner
- Stories

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Publish with GitHub Pages
The project is configured for GitHub Pages from the `main` branch and the repository root (`/(root)`). The published project URL is:

`https://emmanuelpewa1-sudo.github.io/iiasl-website/`

## Updating the website
Edit the relevant HTML file and shared stylesheet in `assets/styles.css`. Add gallery photographs to `assets/` and replace the placeholder tiles in `gallery.html` when images are ready. After making changes, commit and push them to the `main` branch; GitHub Pages will deploy the update automatically.

## Current content notes
- The association logo supplied for this project is in `assets/iiasl-logo.jpg`.
- About, Gallery and Stories contain starter content and clearly marked areas awaiting approved organisational information or photographs.
- The Dinner page includes the programme and menu details supplied for the 27 November 2026 event.
